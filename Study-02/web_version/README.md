# 할 일 관리 앱 - 웹 버전 (데스크톱 최적화)

브라우저에서 바로 사용할 수 있는 가볍고 빠른 할 일 관리 앱입니다. 외부 라이브러리 없이 순수 HTML, CSS, JavaScript로 만들어졌습니다.

🖥️ **이 버전:** 데스크톱 환경에 최적화된 와이드 레이아웃 (1024px 이상)

**주요 특징:** 자동 저장 · 다크 모드 · 카테고리 필터 · 진행률 추적 · 데스크톱 최적화 · 완전한 키보드 조작

## 🎨 디자인 개선 사항 (웹 버전)

### 데스크톱 최적화 레이아웃
- **좌측 사이드바**: 진행률, 카테고리별 현황을 한눈에 보기
- **중앙 입력**: 할 일 입력 & 자동 분류 체크박스
- **하단 그리드**: 할 일들을 카드로 표시 (와이드 화면 활용)

### 시각적 개선
- 진행률 바 크기 증대 (높이 16px)
- 카테고리별 진행률을 개별 카드로 표시
- 할 일 항목들을 그리드 카드 형태로 배치
- 호버 시 그림자 효과 추가

### 반응형 지원
- **1024px 이상**: 사이드바 + 메인 2단 레이아웃
- **768~1024px**: 단일 컬럼 레이아웃
- **360~768px**: 모바일 최적화
- **360px 이하**: 극소형 디바이스 대응

## 빠른 시작

**5분 안에 시작하기:**

1. `index.html` 파일을 브라우저에서 엽니다. (데스크톱 권장)
2. 우측 상단 입력창에 "오늘 할 일" 입력 → Enter
3. 완료하면 카드의 체크박스 클릭 (진행률 자동 갱신)
4. 좌측 사이드바에서 실시간 진행률 추적
5. 종료 후 다시 열어도 모든 데이터 유지됨 ✨

**팁:** 🌙 버튼으로 다크 모드 토글, 필터 탭으로 카테고리별 보기

## 주요 기능

- ✅ **할 일 추가** - Enter 또는 버튼으로 추가
- ✅ **완료 체크** - 체크박스로 토글, 취소선 표시
- ✅ **수정** - 제목 더블클릭 또는 "수정" 버튼
- ✅ **삭제** - "삭제" 버튼, 5초 내 "실행 취소" 가능
- ✅ **카테고리** - 업무 / 개인 / 공부 분류
- ✅ **필터** - 카테고리별 필터링
- ✅ **진행률** - 전체 및 카테고리별 실시간 계산
- ✅ **완료 항목 일괄 삭제** - 완료된 항목을 한 번에 제거
- ✅ **내보내기** - JSON 파일로 백업
- ✅ **가져오기** - 백업한 JSON 파일 복원
- ✅ **자동 카테고리 분류** - 키워드 기반 자동 할당 (선택)
- ✅ **다크 모드** - 🌙 버튼으로 토글
- ✅ **자동 저장** - localStorage에 즉시 저장

| 키 | 설명 | 형식 |
|----|------|------|

## 자동 카테고리 분류

입력창 옆의 **"자동" 체크박스**를 활성화하면 키워드로 자동 분류합니다.

| 카테고리 | 감지 키워드 |
|---------|-----------|
| 업무 | 회의, 보고서, 프로젝트, 팀, 마케팅, 분석, 클라이언트, 계약 |
| 개인 | 쇼핑, 운동, 영화, 친구, 가족, 휴식, 취미, 요리 |
| 공부 | 공부, 숙제, 강의, 시험, 책, 프로그래밍, 자격증 |

**예시:**
- "마케팅 자료 작성" → 자동으로 "업무" 할당
- "영화 보기" → 자동으로 "개인" 할당
- "Python 공부" → 자동으로 "공부" 할당
- 매치되지 않음 → 마지막 사용한 카테고리 사용

💡 **팁:** 체크박스를 해제하면 선택 드롭다운의 카테고리가 사용됩니다.

## ⚠️ 중요한 주의사항

### 데이터 저장 위치
- **브라우저별로 따로 저장** - Chrome, Firefox, Safari 각각 별도의 데이터 저장소
- **기기별로 따로 저장** - 모바일과 PC의 데이터는 별도
- **도메인별로 따로 저장** - `http://localhost`와 `file://`는 다른 저장소

### 데이터 삭제
다음 경우 할 일이 지워집니다:
- 브라우저의 "사이트 데이터 삭제" / "캐시 지우기"
- 브라우저의 "쿠키 및 사이트 데이터 삭제"
- 프라이빗 모드 종료 (모든 데이터 자동 삭제)

### 데이터 백업
**중요한 데이터는 반드시 백업하세요!**

1. 할 일 목록에서 "내보내기" 버튼 클릭
2. `todo-backup-[타임스탐프].json` 파일 자동 다운로드
3. PC의 안전한 위치(예: Documents, Drive 등)에 저장
4. 이 파일은 데이터 손실 시 기록용으로 보관

**예시 파일 내용:**
```json
{
  "version": "1.0",
  "exportedAt": "2026-10-12T15:30:00.000Z",
  "todos": [
    {
      "id": "1728819600000",
      "title": "마케팅 자료 작성",
      "category": "work",
      "completed": true,
      "createdAt": 1728819600000,
      "completedAt": 1728819700000
    }
  ]
}
```

**가져오기 방법:**
1. 할 일 목록에서 "가져오기" 버튼 클릭
2. 이전에 내보낸 `todo-backup-*.json` 파일 선택
3. 파일의 모든 항목이 현재 목록에 추가됨
4. 중복 제거는 수동으로 해야 함 (같은 항목이 중복될 수 있음)

## FAQ

**Q: 자동 카테고리 분류가 틀렸어요.**
A: 체크박스를 해제하고 드롭다운에서 수동으로 선택하세요. 또는 완료 후 항목을 수정해서 카테고리를 변경할 수 있습니다.

**Q: 가져오기 후 항목이 중복되었어요.**
A: 가져오기는 항상 추가만 하고 병합하지 않습니다. 동일한 항목은 수동으로 삭제하세요.

**Q: 다른 브라우저에서는 데이터가 안 보여요.**
A: 각 브라우저는 별도의 localStorage를 사용합니다. "내보내기"로 JSON 파일을 백업한 후 다른 브라우저에서 "가져오기"하세요.

**Q: 모바일에서도 사용 가능한가요?**
A: 네! iOS/Android 모든 브라우저에서 사용 가능합니다. 터치로 쉽게 조작할 수 있습니다.

**Q: 다크 모드 설정이 저장되나요?**
A: 네, 🌙 버튼으로 토글한 설정이 자동 저장됩니다. 다음 방문 시 선택한 모드가 유지됩니다.
