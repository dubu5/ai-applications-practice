# 📋 퀴즈 검증 명령어: quiz-validate

## 🎯 목적
퀴즈 문제에서 '가장', '최초', '최대' 등 **모호한 최상급 표현**을 찾아 개선하도록 제안합니다.

**규칙**: 최상급 표현에는 반드시 **측정 기준, 시점, 범위**를 명시해야 합니다.

---

## 📖 사용 방법

### 1️⃣ 전체 문제 검증
```bash
pwsh .\.claude\commands\quiz-validate.ps1
```

### 2️⃣ 특정 카테고리만 검증
```bash
# history 카테고리만
pwsh .\.claude\commands\quiz-validate.ps1 history

# science 카테고리만
pwsh .\.claude\commands\quiz-validate.ps1 science

# geography 카테고리만
pwsh .\.claude\commands\quiz-validate.ps1 geography

# general 카테고리만
pwsh .\.claude\commands\quiz-validate.ps1 general
```

### 3️⃣ Windows 배치 파일 실행
```bash
.\.claude\commands\quiz-validate.cmd
```

---

## 🔍 검증 항목

### 감지하는 모호한 표현
| 표현 | 감지 기준 | 필요한 정보 |
|------|---------|-----------|
| **가장** | "가장 큰", "가장 넓은" 등 | 측정 기준 (크기, 길이, 높이, 면적 등) |
| **최초** | "최초의", "최초로" 등 | 시점, 연도, 지역 범위 |
| **최대** | "최대의", "최대로" 등 | 최대값 기준 (면적, 인구, 유량 등) |
| **최고** | "최고의", "최고로" 등 | 높이/순위 기준 + 기준 연도 |
| **최소** | "최소의", "최소로" 등 | 최소값 기준 |
| **최장** | "최장의", "최장으로" 등 | 길이/기간 기준 |
| **최단** | "최단의", "최단으로" 등 | 길이/기간 기준 |
| **제일** | "제일 큰", "제일 오래" 등 | 측정 기준 |

### 자동 인정하는 기준 표현
스크립트는 다음이 있으면 기준이 명시된 것으로 간주합니다:
- ✅ `(괄호)` 안의 설명
- ✅ 연도 표시 (`2024년`, `2020년`)
- ✅ "기준" 또는 "기준으로"
- ✅ "약", "대략" 등의 근사 표현
- ✅ 단위 (`km`, `m`, `%` 등)

## 💡 개선 제안 예시

### ❌ 나쁜 예
```json
{
  "question": "세계에서 가장 큰 대륙은?",
  "explanation": "아시아는 세계 최대의 대륙입니다."
}
```
**문제**: "가장 큰" 기준이 불명확
- 넓이인가? 인구인가? 면적인가?

### ✅ 좋은 예
```json
{
  "question": "세계에서 가장 큰 대륙은? (면적 기준)",
  "explanation": "아시아는 세계 최대의 대륙으로 총 면적이 약 4,458만 km²입니다."
}
```
**개선**: 
- 문제에 **(면적 기준)** 추가
- 설명에 구체적 수치 추가

## 🛠️ 기술 세부사항

### 파일 구조
```
.claude/commands/
├── quiz-validate.ps1     # PowerShell 검증 스크립트 (실행)
├── quiz-validate.cmd     # Windows 배치 래퍼
└── quiz-validate.md      # 이 문서
```

### 카테고리 목록
- `history` - 역사 (10문제)
- `science` - 과학 (10문제)
- `geography` - 지리 (10문제)
- `general` - 일반상식 (10문제)

### 반환 코드
- `0` - 검증 성공
- `1` - 파일 없음, 잘못된 카테고리, JSON 파싱 오류
