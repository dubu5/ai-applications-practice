# 📊 퀴즈 범위 검토: quiz-range

## 🎯 목적
퀴즈 문제의 특정 범위를 검토하여 **난이도 분포**와 **정답 분포**를 분석합니다.

---

## 📖 사용 방법

### 기본 문법
```bash
# 1번부터 10번까지 검토
pwsh .\.claude\commands\quiz-range.ps1 1 10

# 11번부터 20번까지 검토
pwsh .\.claude\commands\quiz-range.ps1 11 20

# 전체 범위 검토
pwsh .\.claude\commands\quiz-range.ps1 1 40
```

### Windows 배치 래퍼
```bash
.\.claude\commands\quiz-range.cmd 1 10
```

---

## 📋 검토 항목

### 1️⃣ 난이도 분포
```
난이도별 문제 개수:
├─ 🟢 Easy   : 3개 (30%)
├─ 🟡 Medium : 4개 (40%)
└─ 🔴 Hard   : 3개 (30%)
```

### 2️⃣ 정답 분포
```
정답 선택지 분포:
├─ 선택지 0번 : 3개 (30%)
├─ 선택지 1번 : 2개 (20%)
├─ 선택지 2번 : 3개 (30%)
└─ 선택지 3번 : 2개 (20%)
```

### 3️⃣ 카테고리 분포
```
카테고리별 문제:
├─ 🏛️  History    : 3개 (30%)
├─ 🧪 Science    : 2개 (20%)
├─ 🗺️  Geography  : 3개 (30%)
└─ 📚 General    : 2개 (20%)
```

## ⚙️ 검증 규칙

### 정답 분포 검증
- ❌ **문제**: 같은 정답이 50% 이상
- ✅ **양호**: 정답이 30% 이상 균등 분포

### 난이도 검증
- ❌ **문제**: 같은 난이도가 70% 이상
- ✅ **양호**: 난이도가 적절히 섞여 있음

### 카테고리 검증
- ❌ **문제**: 같은 카테고리가 60% 이상
- ✅ **양호**: 카테고리가 균등하게 분포

## 💡 활용 사례

### 문제 균형 확인
```bash
# 1~20번 검토
pwsh .\.claude\commands\quiz-range.ps1 1 20
```
정답 분포가 불균등하면 새로운 문제 추가 시 고려

### 섹션별 검토
```bash

```

## 📝 자주 묻는 질문

**Q: 범위를 잘못 지정하면?**
```
A: 오류 메시지와 함께 유효한 범위를 안내합니다.
   유효 범위: 1 ~ 40
```

**Q: 정답 분포가 불균등하면?**
```
A: 경고 메시지로 "정답이 편중되어 있습니다"를 표시합니다.
   새로운 문제를 추가할 때 고려하세요.
```

**Q: 같은 범위를 여러 번 검토하면?**
```
A: 매번 새로 계산하여 표시합니다.
   파일은 변경되지 않습니다.
```
