# ➕ 퀴즈 추가 명령어: quiz-add

## 🎯 목적
사용자가 카테고리와 난이도를 지정하면, **Claude가 자동으로** 그 조건에 맞는 문제를 생성하고, 검증 가이드라인을 엄격히 지키면서 `questions.json`에 추가합니다.

---

## 📖 사용 방법 (사용자 입장)

### 기본 문법
```bash
/quiz-add <카테고리> <난이도>
```

### 예시
```bash
# 역사 카테고리, 중간 난이도 문제 추가
/quiz-add 역사 중간

# 과학 카테고리, 어려움 난이도 문제 추가
/quiz-add 과학 어려움

# 지리 카테고리, 쉬움 난이도 문제 추가
/quiz-add 지리 쉬움

# 영문으로도 가능
/quiz-add history medium
/quiz-add science hard
```

|------|------|

## 🤖 Claude의 구현 지침 (이 문서를 읽는 것은 Claude)

### 1단계: 입력 검증
- ARGUMENTS에서 카테고리와 난이도 추출
- 한글입력을 영문으로 변환
- 유효하지 않은 값이면 오류 메시지 출력

### 2단계: 문제 생성
사용자가 지정한 카테고리와 난이도에 맞는 **새로운 문제 1개**를 생성합니다.

#### 생성 규칙
- **형식**: 기존 questions.json의 문제들과 동일한 구조
- **ID**: `{카테고리}_{새로운번호}` (예: history_011)
- **선택지**: 정확히 4개
- **정답**: 0~3 중 하나 (균형있게 분산)

#### 카테고리별 예시 주제
**history (역사)**:
- 한국사: 건축, 문화유산, 인물, 사건, 연도
- 세계사: 주요 역사 사건, 인물, 문명

**science (과학)**:
- 물리: 힘, 에너지, 파동, 천체
- 화학: 원소, 화학반응, 분자구조
- 생물: 세포, 유전, 진화, 생태
- 지구과학: 지질, 기후, 우주

**geography (지리)**:
- 한국지리: 산맥, 강, 도시, 기후
- 세계지리: 대륙, 국가, 자연지형, 기후대

**general (일반상식)**:
- 스포츠, 문화, 기술, 교육, 예술, 음악, 영화

### 3단계: 검증 (필수!)

#### 규칙 1: 정답이 하나뿐인가?
- 다른 해석이 가능하면 괄호로 조건 명시
- 예: "세계에서 가장 큰 대륙은? (면적 기준)"

#### 규칙 2: 최상급 표현에 기준이 있는가?
최상급 표현 목록: 가장, 최초, 최대, 최고, 최소, 최장, 최단, 제일

| 표현 | 필요한 기준 | 예 |
|------|-----------|-----|
| 가장 | 측정 기준 | "가장 긴 뼈는?" → "인간의 골격계 중 가장 긴 뼈는?" |
| 최초 | 시점/연도/범위 | "최초의 문명은?" → "세계 역사상 최초의 문명은?" |
| 최대 | 최대값 기준 | "최대 높이", "최대 면적" 등 명시 |
| 최고 | 높이/순위/연도 | "최고봉의 높이는?" → "세계 최고봉 에베레스트의 높이는?" |
| 최소 | 최소값 기준 | 측정 기준 명시 필수 |

#### 규칙 3: 시간과 범위가 명확한가?
- ❌ "최근에 개발된..." → ✅ "2020년 이후 개발된..."
- ❌ "세계에서 가장 큰..." → ✅ "세계에서 가장 큰... (면적 기준)"
- 변할 수 있는 정보는 반드시 시점 명시

#### 규칙 4: 선택지가 동등 수준인가?
- 모두 비슷한 난이도의 선택지
- 명백히 틀린 답이 아닌, 그럴 듯한 오답
- 혼동하기 쉬운 선택지들로 구성

#### 규칙 5: 중복 검사
- 기존 문제와 유사한 질문은 피하기
- 새로운 관점이나 주제로 구성

#### 검증 실패 시
- 문제를 수정하고 다시 검증
- 불가능하면 새로운 문제 생성

### 4단계: JSON에 추가

#### 생성될 JSON 구조
```json
{
  "id": "history_011",
  "category": "history",
  "question": "훈민정음이 반포된 연도는?",
  "choices": ["1443년", "1440년", "1450년", "1460년"],
  "answerIndex": 0,
  "explanation": "훈민정음은 세종대왕이 1443년에 반포했습니다.",
  "difficulty": "medium",
  "source": "한국사 교과서",
  "active": true
}
```

#### 단계별 진행
1. `questions.json` 읽기
2. 해당 카테고리의 마지막 ID 확인
3. 새로운 ID 생성 (예: history_011)
4. 생성한 문제 객체를 배열에 추가
5. 정렬 유지 (카테고리별로 묶여있는지 확인)
6. JSON 파일에 UTF-8로 저장

### 5단계: 결과 보고

성공 시:
```
✅ 문제가 추가되었습니다!

ID: history_011
카테고리: 역사 (history)
난이도: 중간 (medium)

질문: 훈민정음이 반포된 연도는?
선택지:
  ✓ 0: 1443년
    1: 1440년
    2: 1450년
    3: 1460년

설명: 훈민정음은 세종대왕이 1443년에 반포했습니다.
출처: 한국사 교과서

정답 분포 현황: 정답이 선택지 0번에 속함 (분산 목표: 1, 2, 3번 우선)
```

실패 시:
```
❌ 문제 생성 실패

이유: [오류 내용]
```

## 🎯 정답 분포 균형 (중요!)

**현재 문제**: 정답이 선택지 0번에 편중 (90%)

**목표 분포**:
- 선택지 0번: 25% (10개)
- 선택지 1번: 25% (10개)
- 선택지 2번: 25% (10개)
- 선택지 3번: 25% (10개)

**Claude의 역할**:
- 새 문제를 추가할 때 **반드시 1, 2, 3번에 정답을 우선**으로 배치
- 0번은 피하기
- 이렇게 하면 전체 분포가 균형잡힐 수 있음
